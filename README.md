# 学鉴公开下载流程测试

当前仅用于测试 GitHub 仓库、Release 上传和公开下载流程。

## 测试内容

- `DOWNLOAD-TEST-20261003.txt`：可用记事本打开的纯文本测试文件
- `SHA256SUMS.txt`：测试文件的 SHA256 校验值

在本仓库的 **Releases** 页面打开带“下载流程测试”字样的测试版本，然后在 **Assets** 中下载上述文件。GitHub 自动生成的 `Source code (zip)` / `Source code (tar.gz)` 只是这个测试仓库的内容，不是应用程序。

## 重要说明

本仓库目前没有学鉴安装包、Windows 绿色包或应用程序源码，也不包含账号密钥或师生资料。

学鉴程序仍有待修复问题，Windows 包尚未完成实机验证。此次流程测试不代表软件功能、安装或运行验收通过，请勿作为教学软件使用。

正式程序是否发布、发布哪个版本，需要完成相应修复与验收后另行确认。这里不会自动同步其他仓库或自动发布程序。
